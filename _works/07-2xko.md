2XKO is Riot Games’ free-to-play 2v2 tag-based fighting game set in the world of Runeterra. 
Built for both longtime fighting game players and newcomers, the game combines fast-paced team combat, deep strategic mechanics, and accessible controls with the stylized characters and universe of League of Legends. 

I am currently a **Staff Software Engineer** on the team, owning the core UI architecture of the game as well as various around game features built on top of it.

## Core UI Architecture - Tech Lead
I led the project's transition from prototype UI widgets and messy developer workflows to a comprehensive solution with UI foundational tech, core UI systems, and fleshed out best practices for building menus and clientside features.
This was a monumental effort that took many engineers around 2 years to fully implement and harden.
> Because we are a live service game, stability in our systems is paramount to supporting our "forever" game.

Things we needed to consider when designing the UI architecture:
- Extensibility
- Clear API design
- Developer workflows
- Seasonal and dynamic content
- Controller support

This work was so impactful that I got the opportunity to share it at **GDC 2026**. Read about it here:

I continue to make improvements to our UI architecture, write out documentation, and help spread knowledge on how to use our systems to our game feature teams.

## Other Features and Responsibilities
- Built a universal camera manager that unified our previous multi-camera solution and streamlined the logic around who owns the game camera and how ownership is transferred between modes (ex. in menus, lobby, gameplay)
- Implemented lobby loading to allow lobbies, game matches, and menus to coexist. This allows us to be in lobby, spectate a game, and open up the pause menu very flexibly.
