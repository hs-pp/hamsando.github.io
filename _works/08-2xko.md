2XKO is Riot Games’ free-to-play 2v2 tag-based fighting game set in the world of Runeterra. Built for both longtime fighting game players and newcomers, the game combines fast-paced team combat, deep strategic mechanics, and accessible controls with the stylized characters and universe of League of Legends. Players assemble teams of iconic champions, coordinate assists and tag mechanics, and compete in high-intensity matches designed around both competitive depth and player expression.

I am currently a **Staff Software Engineer** on the team, owning the core UI architecture of the game as well as various around game features built on top of it.

## Core UI Architecture - Tech Lead
The building of the core UI architecture was a monumental effort that I got to design and lead. I transitioned our team away from inconsistent development patterns into a comprehensive solution that would allow us to build much more sustainable UI menus and widgets that fit right in to the greater UI ecosystem.

> Because we are a live service game, stability in our systems is paramount to supporting our "forever" game.

Things I needed to consider when designing and developing the UI architecture:
- Extensibility
- Clear API design
- Developer workflows
- Seasonal and dynamic content
- Controller support

This work was so impactful that I got the opportunity to share it at **GDC 2026**. Read about it here.
